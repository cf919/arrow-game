# 一箭又一箭
## 游戏简介
本项目是基于Pygame开发的益智解谜小游戏，游戏棋盘为6×6网格，棋盘上分布上、下、左、右四个方向的箭头。玩家点击箭头，箭头会沿着指向方向尝试飞出棋盘；路径被阻挡则会触发失误，清空棋盘全部箭头即可通关关卡。程序包含开始、游戏、胜利、失败四种游戏状态，支持多关卡切换，游戏过程中可随时重置当前关卡。

## 开发环境
- Python 3.8及以上版本
- pygame 2.5.x

## 安装和运行方法
1. 安装pygame依赖库
```bash
pip install pygame
```

2. 克隆或者下载本项目源码
3. 在项目目录下执行程序

```
python main.py
```

## 游戏操作说明

1. 点击**开始游戏**按钮，进入第一关游戏。
2. 点击棋盘格子上的蓝色箭头：
   - 若箭头前进路径没有其他箭头阻挡，箭头播放飞行动画，飞出棋盘后消失。
   - 若前进路径存在其他箭头阻挡，箭头红色闪烁提示碰撞反馈，消耗一次失误机会。
3. 界面右上角**重新开始**按钮：随时重置当前关卡。
4. 棋盘所有箭头全部飞出，本关通关，点击下一关继续挑战。
5. 失误次数耗尽，游戏失败，可点击重新开始重试本关卡。
